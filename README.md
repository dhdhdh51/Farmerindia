# Kisan Ledger (Android Java + XML)

Offline-first farming management app for Indian farmers.

## Stack
- Java + XML
- Room database
- MVVM-ready structure
- WorkManager reminders
- MPAndroidChart
- Glide
- Gson
- Lottie
- OSM map SDK

## Features Included
- Splash + onboarding
- Dashboard cards and expense summary
- Field, expenses, fertilizer, watering, reports, diary, settings, backup pages
- Local storage only (no auth, no cloud)
- Hindi/English string resources
- Dark mode preference scaffold
- GitHub Action for debug APK build

## Run
1. Open in Android Studio Hedgehog+
2. Sync Gradle
3. Run app on Android 8+ device/emulator
